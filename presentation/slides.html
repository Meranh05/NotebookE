  • API-first — mọi tính năng đều có REST API

Đặc điểm kiến trúc

🔗 API-First

Mọi tính năng đều qua REST API. Frontend chỉ là client — không truy cập DB trực tiếp. Next.js proxy /api/* về FastAPI.

⚡ Async-First

Toàn bộ I/O bất đồng bộ: DB queries, LLM calls, file I/O, graph invocations. Sử dụng async/await xuyên suốt.

🧩 Domain-Driven Design

Phân tách rõ: Domain Models (Pydantic) → Repository (SurrealQL) → Services → Routers.

🔄 Job Queue

Long-running tasks (embed, podcast, source processing) chạy background qua Surreal-Commands worker. UI poll trạng thái.

Luồng Xử Lý: Ask — Tìm Kiếm Thông Minh
LangGraph Workflow — AI lập chiến lược tìm kiếm, tổng hợp câu trả lời

Quy trình 4 bước

1
Agent — Plan Strategy
LLM phân tích câu hỏi → sinh ra Strategy: danh sách search terms + instructions
2
Trigger Queries (Fan-out)
Mỗi search term → Send("provide_answer") — chạy song song
3
Provide Answer (×N)
Vector search (cosine similarity) → top 10 kết quả → LLM tổng hợp sub-answer
4
Write Final Answer
LLM tổng hợp tất cả sub-answers → final answer + citations

Tính năng nổi bật

  • Streaming: strategy → answers → final_answer (real-time)
  • Parallel processing: nhiều search chạy đồng thời
  • Dual search: Full-text (BM25) + Vector (cosine)
  • Citations: trích dẫn nguồn trong kết quả

Design Patterns & Triển Khai
Các mẫu thiết kế áp dụng trong hệ thống và phương thức triển khai

🏗️ Design Patterns sử dụng

Domain-Driven Design (DDD)

Domain Models (Pydantic) chứa business logic. ObjectModel base class: save(), get(), delete().

Repository Pattern

Data access layer trung gian: repo_query(), repo_create(), repo_upsert(). Tách biệt logic DB.

State Machine (LangGraph)

6 workflow graphs: nodes + edges + fan-out. Debuggable, maintainable AI orchestration.

Command / Job Queue

Fire-and-forget: submit → worker process → poll status. Tránh timeout cho long tasks.

Adapter (Provider Abstraction)

Esperanto: unified interface cho 18+ AI providers. Per-request model override.

🚀 Triển khai hệ thống

Docker Compose (Production)

2 containers: surrealdb (DB) + notebooke (API + Frontend + Worker). Chạy docker compose up -d → ready in 20s.

Development (Local)

make database → SurrealDB
make api → FastAPI (auto-migrate)
make worker-start → Background worker
make frontend → Next.js dev server

✅ Kết quả đạt được

  • Kiến trúc 3 tầng rõ ràng, async-first, scalable
  • 18+ AI providers — không vendor lock-in
  • Multi-model DB (graph + vector + full-text) trong 1 hệ thống
  • 6 LangGraph workflows cho AI orchestration
  • Podcast generation đa speaker chuyên nghiệp
  • REST API đầy đủ (24 routers, auto-docs)
  • Job queue cho long-running tasks — UX mượt
  • Privacy-first — self-hosted, mã hóa credentials

⚠️ Hạn chế

  • Single-user (chưa hỗ trợ multi-user)
  • Auth cơ bản (password-only, chưa OAuth/JWT)
  • SurrealDB còn tương đối mới, cộng đồng nhỏ
  • Citation cơ bản (chưa bằng Google Notebook LM)
